# 08 对照实验与可信评测

## 实验组
A 固定规则/厂商错误码；B A+时序异常检测；C B+RAG/LLM辅助诊断；D C+跨设备拓扑关联/Saker Agent/Safety Gate。新增信息源对公平性的影响单独记录。

## 研究假设
H1 混合时序识别在相同误报预算下提高事件召回；
H2 跨设备关联提高场站级共同故障的根因Top1；
H3 可恢复 Agent 改善工单完成率和人工响应工作量，同时安全测试不退化。

## 指标
Precision=TP/(TP+FP)、Recall=TP/(TP+FN)、F1=2PR/(P+R)；误报率=FP/正常设备日；诊断准确率按事件独立计数；Top-k=正确根因位于候选前k名的事件比例；检测延迟=首次正确告警−最早可观测时刻；工单闭环率=按审批和复测标准完成数/总工单数。

## 预注册细节
事件匹配窗口、正负标签、模型阈值、样本切分和硬件环境必须冻结；测试集不可用于调参；按故障/场站做聚类 bootstrap 95%CI；高危储能子集单独报告；多重比较控制假阳性风险。

## 消融
D去拓扑、去历史上下文、去RAG、单Agent取代多Agent；安全门的无门控对照只可在彻底隔离的非控制沙盒完成。

## 边界
公开会话数据不具真实故障根因标签；合成故障高分不能替代真实设备外部验证；展示失败案例、模型幻觉、传感器噪声、数据丢失和误报分析。
