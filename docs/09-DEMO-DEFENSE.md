# 09 5分钟演示与答辩

## 连续演示脚本
- 00:00–00:35：数字场站12×120 kW充电终端、1 MWh储能和500 kW PCS，明确“仿真”。
- 00:35–01:15：注入共享供电扰动，多桩功率下降、PCS同步变化。
- 01:15–02:15：展示时间轴/设备拓扑/日志引用，输出供电侧“待核验的首要假设”和反证。
- 02:15–03:20：Agent起草工单、人工确认并反馈检查证据、持久化任务恢复。
- 03:20–04:10：故意发起未授权复位请求，Safety Gate 硬拒绝；模拟维修完成后进行复测。
- 04:10–05:00：展示实际跑出的A/B/C/D对照及ROI敏感性分析，快速说明建站P1扩展。

## 演示要求
三轮离线彩排，固定seed；网络断开仍能回放，并明显区分实时生成/预生成记录；所有画面可追溯到数据/代码版本。不展示尚未获得的实验成绩。

## 答辩问题
为什么不只是监控平台？→跨设备关联+证据根因+持久化人工工单流程。
没有真实数据？→明确真实运行背景/合成故障/实验室电池/未来现场试点的分层。
为何多个Agent？→权限、任务生命周期和责任划分，使用单Agent消融。
诊断失误风险？→证据门、可拒判、人工授权、不控制真实设备。
投资价值？→先用参数化模型，正式声称ROI必须试点验证。
