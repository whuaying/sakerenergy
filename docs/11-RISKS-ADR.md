# 11 风险清单和架构决策

|风险|后果|缓解|
|---|---|---|
|缺少真实故障标签|外部有效性不足|来源分层及真实影子试点|
|LLM误诊|不安全的检修建议|硬门控、拒判、人工审批|
|协议不统一|设备对接成本高|适配器封装、限定试点型号|
|仿真过拟合|实验结果失真|难负例、跨拓扑测试|
|公网断连|比赛演示失败|可标注的离线回放|
|数据/开源许可不明|法律商业风险|数据和依赖许可证登记|
|范围过大|核心功能失败|优先P0，建站留P1|

## ADR
ADR001 Go业务平台 + Python检测模型；
ADR002 LLM仅拥有只读查询与工单草拟工具；
ADR003 规范化事件，同时保留原始测点；
ADR004 评分真值与模型输入物理隔离；
ADR005 演示显式标注仿真和预计算结果；
ADR006 所有工业控制依赖原有独立安全保护。
