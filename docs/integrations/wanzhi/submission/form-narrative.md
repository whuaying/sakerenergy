**作品名称**：Saker Energy 充储场站证据诊断助手

**作品类型**：应用赛

**一句话简介**：基于万智平台专属员工与本地只读工具链的充储场站告警根因诊断系统——证据不足不妄断、主动只读补证、无法定论转人工。

**一、任务解决（30%）**
针对充储场站「多设备功率同窗下降」类告警，实现完整的证据驱动诊断闭环：
- 事件证据包化输入：时间窗、测点功率、拓扑事实、数据质量与缺失标记结构化上送；
- 首轮输出 3 条候选原因（上游供电 / 站级调度 / 测量对时）并 abstain，不臆断根因；
- 主动请求只读补证（Q01 母线电压），本地白名单查询执行后回发同一会话；
- 第二轮依据新证据修订候选（增加反证 E04、不误判调度限功率），评估证据价值后输出 7 项人工核验清单转人工；
- 全部决策经本地 Schema + 语义合同校验（引用必须属于本轮证据，不编造测量/来源）。

**二、工程化落地（30%）**
- 真实万智开放 API 集成：创建会话 → 发送证据 → 流式解析 → 取结果 → 对账恢复，全程记录 session_id 与 run 记录；
- 只读安全边界：白名单查询 telemetry_window，无设备控制指令；密钥 DPAPI 加密仅存服务端，不入前端与公开仓库；
- 可靠性：失败/断流/超时对账不重发（UNKNOWN_REMOTE_STATE / RESULT_NOT_VALIDATED 可恢复）；预算机制防无限循环（最多三次补证）；
- 质量保障：本地 55 项离线测试（传输 / Schema / 引用 / 幂等 / 超时 / 恢复），6 轮真实 API 调用全部 VALIDATED_ADVISORY；
- 交付物：作品说明书（PDF）、演示视频（MP4，含真实调用回放）、大屏最小集成 demo 页面、公开 Agent URL 可复现。

**三、实际应用效果（25%）**
- 6 轮真实万智 API 调用（2026-10-29）全部通过合同校验，覆盖正常返回、预算耗尽、电压异常、电压缺失、行业场景与补证闭环；
- 行业场景（充储场站 BUS-B 拓扑）双轮补证闭环实测：首轮 1087 帧 → 本地只读补证（母线电压 396V 模拟读数，已标注）→ 第二轮 1008 帧修订转人工；
- 关键数字可复现：session 8f8b1405cefe45c7、run 6094ff82/c1b6bccc、Agent ID d86bc562cb9b450b（演示数据为行业 fixture，已明确标注，不冒充现场遥测）。

**四、业务落地潜力（15%）**
- 场景真实：充电桩与储能变流器同挂母线、功率同窗下降是充储一体场站的常见告警形态；
- 落地路径：以「诊断建议 + 人工核验清单」方式输出，与运维工单流程天然衔接，不替代有资质人员决策；
- 扩展方向：知识库绑定自有故障分类与检查规程、更多只读数据源接入、多站试点。

**安全与数据声明**：演示事件与遥测为行业演示数据（INDUSTRY_DEMO_FIXTURE），非真实场站测量；本作品不发送任何设备控制指令；提交材料中的真实 API 调用记录可经公开 URL 与回放核验。
