## 成片与来源

- 总长265秒（4分25秒），1920×1080，24fps，H.264 / yuv420p + AAC / 48kHz / 双声道，5,242,771字节，小于200MB。
- 15秒黑色片头与标题淡入淡出；250秒演示；八段中文解说、同步分段字幕、全程演示来源标注和结尾Agent入口。
- 解说逐字取自 `MP4-demo-storyboard.md` 的八行台词，用本机 Microsoft Huihui Desktop 离线生成并分别放置在1、24、47、74、109、144、179、215秒。无外部TTS上传，也未使用账户密钥。
- 桌面窗口控制失败，自动审批拒绝命令行启动Chrome/桌面采集的组合操作；改用浏览器接口直接连续采集本地演示页的viewport，避免其他应用和恢复气泡进入视频。没有将此方式描述为Chrome桌面录屏。
- 浏览器采集4,552帧，实际平均约18.2fps，按采集时间戳重采样编码为24fps。因页面恢复旧滚动位置，回放最初8秒改用预检时采集的真实首页静帧；其余使用连续采集帧。
- 原有120秒配音音频头异常、旧raw-recording.mp4缺少moov，均未用于成片，保留在本机并加入Git忽略。原始浏览器帧、合成音轨与字体副本位于被忽略的 `backend/.private/video-work/`。

## 验收证据

1. ffprobe检查编码、分辨率、像素格式、帧率、音频、时长和文件大小；全片FFmpeg解码无错误。
2. `video-qa/`保存5、19、35、65、90、125、159、195、235秒九个成片关键帧，检查片头、hero、事件卡、分析、首轮、396V补证、转人工、安全区和汇总；无桌面应用、Chrome恢复气泡或其他软件遮挡。
3. PDF文字抽取确认396、50、1087、1008、session `8f8b1405cefe45c7`、Agent ID `d86bc562cb9b450b`均存在，且与页面一致。PDF没有列出两个run前缀；`6094ff82`与`c1b6bccc`另与本机原始run核对，状态、同一session、1087/1008帧及INDUSTRY_DEMO_FIXTURE来源均匹配。
4. 片头、页面和视频叠字保留 `INDUSTRY_DEMO_FIXTURE（演示）` 与非现场遥测说明。
5. 使用本机FFplay对修订成片完整有声播放，播放结束状态及A/V时钟统计另写入 [video-verification.json](video-verification.json)。这是播放器时钟、图像与台词时间表的技术核对，不代替人工听感评分。
6. 同批复核：网站9页构建检查通过，官网7项测试通过，当前后端55项离线测试通过。视频保留说明书及脚本冻结的“50项”口径，不将后续新增测试误写为早期验收。

机器校验与文件SHA-256见 [video-verification.json](video-verification.json)。本机也可双击 [video-preview.html](video-preview.html) 查看成片。

## 本机重新合成

`build_demo_video.py prepare`从分镜生成配音计划；运行 `generate_demo_voice.ps1` 生成八段离线配音；浏览器采集帧及capture.json就绪后执行 `build_demo_video.py assemble`。视频生成器使用既有FFmpeg/ffprobe，源截图缓存不会上传Git。缺少本机帧缓存时需要重新采集，脚本不会伪造页面画面。

视频展示历史真实API输出的本地回放与模拟遥测，不证明现场故障诊断准确率、真实设备接入、维修恢复或获奖结果。
