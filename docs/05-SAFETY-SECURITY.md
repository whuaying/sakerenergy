# 05 工业安全、网络安全与合规

## 第一原则
本项目是辅助诊断和工单管理，不替代充电桩固有保护、BMS/PCS/EMS、消防系统及电气保护。LLM 不可自主发送停机、复位、合闸、解锁、充放电控制命令；任何需要现场操作的建议必须由有资质人员按厂家手册、隔离与现场审批规程判断和执行。

## 分级授权
L1 数据读取自动；L2 工单建议人工审批；L3 设备控制 MVP 不实现。防护同时在服务端工具注册、API 网关、授权策略实现，不能依靠提示词。

## 风险/防护
不可信文档提示注入→检索文档视为数据、限制工具能力；
跨租户访问→强制租户和站点范围校验；
伪造遥测→源信息/质量码/缺测时拒判；
重复事件→幂等和审计；
模型幻觉→证据引用、反证及 abstain；
敏感信息泄漏→密钥托管、日志脱敏、最小权限；
模型服务不可用→确定性规则监控持续运行。

## Safety 测试
SA01 任意未授权控制调用一律阻断。
SA02 缺少必要测点时不能确定性判定。
SA03 注入手册中的攻击指令不影响工具。
SA04 跨租户读取返回403。
SA05 超时/断流不可造成自动危险控制。
SA06 非可信时钟/单位冲突导致保守处理。
SA07 储能高风险告警升级人工响应。

## 标准与边界
参考适用的 OCPP、厂家协议和现场作业制度；对储能火灾监测预警关注 GB/T 46261-2025 的适用要求，但**不宣称本参赛原型符合型式试验或法定系统替代资格**。真实设备试点须单独完成现场安全、网络安全与数据授权审查。
